# Suno Librarian

This utility is designed to download all the Suno songs you have created and their associated metadata. It is highly advisable to ONLY use this app on your own library of songs you have created and have the rights to. I am no expert on the Suno TOS, use at your own risk! 

## Current Features
- Highly configurable options
- Downloads MP3 and/or WAV files of songs from your Suno library
- Captures generated artwork for each song
- Captures all metadata for your songs including:
    - Title
    - Artist
    - Creation Date
    - Prompt
    - Slider Values (Weirdness, Style Influence, Audio Influence)
    - Tags (auto-generated by Suno from your prompt)
    - Lyrics (if any)
- Saves/Converts downloaded songs as any or all of WAV, MP3, ALAC (m4a), FLAC and can be configured to embed metadata, artwork, and lyrics in all of the compressed versions.

More documentation coming soon.

## Technical Details
The app is written in Typescript and runs on Node v24.11.1.

## Prerequisites
- [Node v24.11.1](https://nodejs.org/en/download) (earlier versions very well may work but have not been tested).
- [Google Chrome](https://support.google.com/chrome/answer/95346?hl=en&co=GENIE.Platform%3DDesktop#) (in theory any Puppeteer supporting browser can be used although the code may require some tweaking when the browser is initially launched).
### Audio File Converters/Metadata Utilities 
All of these are called by the program and should be accesible from whatever PATH node apps are aware of.
- [ffmpeg](https://ffmpeg.org/download.html) - For all audio file conversions
- [flactools](https://xiph.org/flac/download.html) - For FLAC metadata embedding
- [Atomic Parsley](https://github.com/wez/atomicparsley) - For ALAC/MP4 metadata embedding
- [kid3](https://kid3.kde.org/#download) - For MP3 metadat embedding

## Installation/Basic Usage
- Clone this repo.
- `cd` to the directory.
- Copy `config/default-config.json` to a `config/config.json`. Modify any values you'd like in `config/config.json`.
- Run `npm run install_global`
- To start the program run `suno-librarian` from your command-line
- When the program starts, it will open a debug instance of your browser and drop you on Suno. You will likely need to login. Login on the browser and then press enter to continue in the terminal.
- As long as you don't delete the directory referenced in the `chromeTempUserDataDirPath` config setting, it's unlikely you will have to login again until your token/cookie expires.
- Once you are logged in the program should start crawling your library, gathering metadata, downloading your music, and running any conversion you want. There is also an option in the config to copy any processed downloaded files to additional paths.
- The console should provide running details of how the job is going.
- As the program reaches the end of the list of songs in each page, it advances to the next and startes over.
